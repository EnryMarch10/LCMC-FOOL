# FOOL Compiler

Project implementing a Functional Object Oriented Language Compiler for the course
[Languages, Compilers and Computational Models - a.y. 2025-2026](https://www.unibo.it/en/teaching/course-unit-catalogue/course-unit/2025/526519)
([Computer Science and Engineering](https://corsi.unibo.it/2cycle/ComputerScienceEngineering)).

## Authors

- [@AR0018](https://github.com/AR0018)
- [@EnryMarch10](https://github.com/EnryMarch10)

## Description

Compiler developed as an extension of the final laboratory version provided for the
Languages, Compilers and Computational Models course (a.y. 2025–2026).
The project extends the original compiler by modifying the files in the `compiler` package,
as required by the course assignment.
