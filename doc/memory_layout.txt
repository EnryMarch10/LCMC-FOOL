MEMORY LAYOUT

CODE section is a separated memory regulated by a register called instruction pointer.
STACK grows from top to bottom.
HEALP grows from bottom to top.
Top is equivalent to address MEMSIZE, a large number, bottom to address 0.

AR -> activation record (also called frame)
CL -> control link (points to previous activation record)
AL -> access link (points to previous activation record of declaration)
* -> a number, word atomic cell of the memory
"" -> same as above/below
... -> other memory with unspecified WORDs (could be structured or empty)

## 1. GLOBAL ENVIRONMNENT ACTIVATION RECORD:
########################################################################################################################
[MEMSIZE - TOP OF THE STACK]  <- $fp (set to initial value of $sp, MEMSIZE)
* fake Return Address to 0
* value/address first var/func declared       [offset -2]
* value/address second var/func declared      [offset -3]
""
* value/address last (n-th) var/func declared [offset -(n + 1)]
...
[0 - BOTTOM OF THE STACK]
########################################################################################################################

## 2. LAYOUT FUNCTION ACTIVATION RECORDS:
########################################################################################################################
[MEMSIZE - TOP OF THE STACK]
...
* CL:address (fp) of caller AR
* value of last (m-th) parameter              [offset m]
""
* value of first parameter                    [offset 1]
* AL:address (fp) of declarations AR: <- $fp in function body
    solves 2 problems:
      1. convenient offset to 0,
      2. not pointing to first parameter gives the possibility to have functions with 0 parameters
* Return Address
* value/address first var/func declared       [offset -2] (for a variable is a value, for a function an address)
* value/address second var/func declared      [offset -3]
""
* value/address last (n-th) var/func declared [offset -(n + 1)]
...
[0 - BOTTOM OF THE STACK]
########################################################################################################################
